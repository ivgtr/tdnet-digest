# 決算要約の結果整合性と操作ストーリー

基準は main `5cd5e6e` / v0.7.9。分析指紋を v105 に更新し、旧抽出・旧表示の成功キャッシュを新しい結果として使わない。実行履歴の保持は要約キャッシュとは独立する。

## 不具合と修正の境界

- 別の閉セルの金額と増減率が近いと、横方向の数量組立が結合していた。`3,963,389` + `16.6` は数値として消え、`100` + `20` は誤った `10020` になり得た。原文字→span、円銭の再結合、span→quantity、段落の横連結/折返し、表示用数量、保存原文の再検証で同じ物理セル所有を使う。最小の一意な閉セルだけを証拠とし、別セル・曖昧な所属を結合しない。距離閾値は縮めず、同セルの符号・小数・桁区切り・範囲を保持する。
- 冒頭は当期より `key` を優先していた。原文表紙と連続する明示フィールドの対象期・主体・連結/個別・会計基準を使い、当期の主要実績を固定順で選ぶ。前年・予想・率・EPS・別主体/範囲を欠損の代用にしない。不明なら推測せず明示し、確認済み本文は残す。標準決算の表は対象期・実績/予想別に分ける。
- 26頁を通した確認で、2頁の個別業績表の「経常利益」が連結IFRSの必須項目に混ざる不足も見つかった。必須指標の宣言元にも報告対象の主体/範囲/基準を適用する。明示的な別属性だけを除き、属性未解決を理由に義務を消さない。「税引前利益」を「経常利益」に改名しない。
- 診断は全体の最新1実行から、実行ID別の保持へ変更。保存結果にも実行IDを残し、JSON取得でPDF URL・結果ID・実行IDを照合する。別の実行の診断を借りない。保存読込/コピーを理由にAPIを再実行しない。

従来の不足は、(1) 同一行の閉セル境界、(2) `other` の数値受理だけでは証明できない決算冒頭、(3) 単一PDFかつcaseごとにstorageを消すsmokeでは証明できないA→B→A、(4) 全文内の異なる報告範囲からの必須指標漏入。最終レビューでは、段落の再結合から誤数量を再生成する経路、タイトルに省略された範囲/基準を別の表紙フィールドから引き継がない経路も追加で検出した。これらも生成候補・表示数量・保存再検証まで追う。既存のコピー・設定・保存失敗を全経路へ複製せず、責務間の接点だけ追加する。

## 診断の保持契約

- `summaryDiagnosticsV1` は Background の直列queueで1キーを原子的に更新する。
- 最大12実行、ストアJSONのUTF-8最大2 MiB、1実行最大192 KiB。長い生応答等を省略した記録は `compaction` に元サイズと理由を残す。識別子・ハッシュ・成否は切り詰めない。
- 追加するrunを保持し、古い完了runを先に除く。すべて進行中でも上限は維持する。診断の削除で要約本文のcacheは消さない。
- 旧最新診断は厳密一致するときだけ利用する。新規保存時には同じ上限で移行し、新storeの保存後に旧キーを削除する。整理失敗は成功本文/保存済み診断を残して警告する。
- APIキー、認証ヘッダー、設定一式、APIエンドポイントは診断オブジェクトへコピーしない。許可した診断フィールドだけを投影する。
- Optionsの既存cache削除は要約/採点/追加分析が対象。診断はこの有限保持で独立して整理される。診断管理UIや無制限の履歴は追加しない。

## 再現と検証

通常の `npm test` はブラウザー・実API・ダウンロード済みPDFを必要としない。原表紙fixtureはPDF.jsの文字/描画入力のみで、PDF本体をcommitしない。原文の値・座標は表紙画像から独立に照合した。

- 公開PDF: https://www.release.tdnet.info/inbs/140120261008547647.pdf
- SHA-256: `ed8e4105ee93a8fb44c294f5be9f88cce9adb1e8e2500d977be3c0a02d726ecf`
- 2026年8月期連結の売上収益3,963,389、営業利益743,128、税引前利益802,505、親会社利益542,516（百万円）。前年は売上3,400,539、営業564,265、親会社利益433,009。次期予想を当期に混ぜない。

```bash
node --import tsx evaluation/scripts/check-earnings-story.ts /path/to/140120261008547647.pdf
npm test
npm run type-check
npm run lint
npm run build
node --import tsx evaluation/scripts/check-extension-smoke.ts --browser-module /path/to/playwright/index.mjs --browser-executable /path/to/chromium
```

26頁の再生は入力PDFのSHAを確認し、全頁を本番と同じPDF.js経路で再抽出する。候補は独立固定値、任意説明は空の固定応答とし、実モデルの成功率を主張しない。外部fetchは固定URLの模擬応答だけで、実APIは呼ばない。結果は `evaluation/results/local/earnings-user-story.{json,html,md}`。実Chromeが起動できない場合、固定応答/React/保存再検証の成功と区別し、実拡張通信・ブラウザー画面の成功とは扱わない。

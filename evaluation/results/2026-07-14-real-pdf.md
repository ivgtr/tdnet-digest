# TDnet実PDFスモーク評価（2026-07-14）

## 対象

- TDnet公式の公開PDF 11件
- 11文書タイプを各1件
- 公開日は2026年7月14日を中心とし、当日に存在しなかった株式分割とM&Aは直近資料を使用
- PDFは`/tmp/tdnet-real-eval`へ一時保存し、リポジトリには公式URLとメタデータだけを保存

PDF.jsはフォント関連の警告を出した資料があったものの、全ページから文字を抽出でき、指定した主要語も確認できた。

## 発見した不具合

1. `株式分割...配当予想の修正`は、配当判定が株式分割より先に実行されるため`dividend`になる。期待値は`stockSplit`。
2. `人事異動に関するお知らせ`は、ガバナンス用パターンに`人事異動`がなく`other`になる。
3. `第１四半期`と`ＩＦＲＳ`の全角英数字を正規化していないため、`fullYear`かつ`jpGaap`になる。

既知不具合は`real-pdf-corpus.test.ts`で`it.fails`として固定した。修正によって期待どおり通るようになるとテストが失敗するため、通常テストへ切り替える必要がある。

## LLM評価を実行していない理由

CLI環境にOpenAI、Anthropic、OpenRouter、GoogleのAPIキーが設定されていなかった。Chrome拡張の同期ストレージに保存されたAPIキーは読み出していない。APIキーをソース、結果、ログへ保存しない方針を維持した。

## 再実行

公式URLからPDFを取得して任意のディレクトリへ保存後、次を実行する。

```bash
node evaluation/scripts/check-real-pdfs.mjs /path/to/pdf-directory
npm test -- --run src/lib/real-pdf-corpus.test.ts
```

LLM評価の次段階では、少なくとも決算、業績修正、配当、株主優待の4件について人手の期待値JSONを作り、主要数値一致、根拠ページ一致、JSON検証成功率を計測する。

# 独立した表のセル探索と抽出エラー診断（2026-10-08）

基準は `bfdd545`（v0.7.8）。[対象PDF](https://www.release.tdnet.info/inbs/140120261008547647.pdf) は26ページ、SHA-256は `ed8e4105ee93a8fb44c294f5be9f88cce9adb1e8e2500d977be3c0a02d726ecf`。旧版では表紙の文字・描画演算は読めるが、独立した表の軸の組合せが増え、`SOURCE_DRAWING:表のセル解析の処理上限` で停止した。旧調査の `validatePages` 成功は抽出できた25ページだけで、PDF全体の成功ではなかった。

### 変更と担当テスト

- `table-layout` は既存の最小幅8・高さ4と連続する上辺・左辺を必要条件として探索を絞る。軸ごとの実罫線を再利用し、辺が途切れた後の遠い軸も探索しない。実罫線・許容幅・最小閉矩形の順序は不変。罫線2,000本と候補100,000回の上限を維持し、枝刈りの開始点・左辺探索にも各100,000回の上限を置く。既に旧上限内だった入力では、各追加カウントは旧候補数以下になる。
- `table-layout.test.ts` は独立6表、結合セル、最小寸法、分割線の許容幅、欠けた各辺、密なセルと疎なページの上限を担当する。企業・PDFごとの例外や文字だけへの代替は加えない。
- `offscreen/index.test.ts` は一部成功後のページ読込・文字・演算・レイアウト失敗、後始末による元例外の上書き防止、文書読込失敗を確認する。`background/index.test.ts` はJSON通信後のページ・段階・例外名・コード・元メッセージを `pdfExtractionError` に保存し、LLMを呼ばず停止することと接頭辞の重複防止を担当する。
- `useSummarize.test.ts` は診断コピー中の拡張無効化を同期例外・非同期拒否で確認する。TDnetページの再読み込みを案内し、コピー済みと表示しない。

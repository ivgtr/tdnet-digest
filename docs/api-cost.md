# APIコストの目安

OpenRouter経由での利用時のコスト目安です。日本円は1ドル=150円で換算しています。

## 前提条件

- **入力トークン**: 約56,000トークン（全文抽出モード、決算短信PDF）
- **出力トークン**: 約800トークン（1パス）/ 約1,600トークン（2パス合計）
- 2パスモードではAPIリクエストが2回発生するため、コストは約2倍になります

## モード選択の指針

| 観点 | 1パス | 2パス |
|---|---|---|
| **コスト** | 低い | 約2倍 |
| **速度** | 速い | 約2倍の時間 |
| **出力安定性** | モデル依存 | 高い |
| **推奨ケース** | 高性能モデル利用時 | 低コストモデル・出力が不安定な場合 |

# API利用料金の目安

要約のAPI料金は、モデルの単価、入力・出力トークン数、呼び出し回数で決まります。概算は各呼び出しについて次の式で計算してください。

`（入力トークン数 × 入力単価 + 出力トークン数 × 出力単価）÷ 1,000,000`

モデルの単価と利用量は契約先の最新表示を確認してください。PDFのページ数や文字数からトークン数を正確には決められません。

## この拡張の呼び出し

| 操作 | 通常のLLM呼び出し | 条件付きの追加処理 |
| --- | --- | --- |
| 要約 | 抽出テキストから構造化事実を1回生成 | 原文照合に失敗した場合だけ1回修復。再失敗ならエラー |
| 実験的スコアON | 要約表示後に採点用の抽出・推論 | 必要時に過去資料を検索・照合 |
| 追加分析 | ボタンを押した場合だけ1回生成 | 要約・採点とは独立 |

要約のキャッシュがあれば再生成しません。採点と追加分析も別にキャッシュします。費用にはモデルが生成する推論トークン、検索サービスの料金、税などが加わる場合があります。

## PDF入力方式

この拡張はPDF.jsで文字を抽出し、抽出テキストをLLMへ送ります。PDFファイルを直接送る方式は既定で使用しません。3件の公開開示資料を使った比較では、PDF直接入力に精度上の利点は確認できず、課金対象の入力が増えました。この結果だけで画像中心のPDFや他のモデルに一般化はできません。

[OpenAIのPDF入力](https://developers.openai.com/api/docs/guides/file-inputs)と[AnthropicのPDF対応](https://platform.claude.com/docs/en/build-with-claude/pdf-support)では、抽出テキストに加えてページ画像も処理されます。[OpenRouterのPDF入力](https://openrouter.ai/docs/guides/overview/multimodal/pdfs)には複数の解析経路があります。直接入力を検討する場合は、利用するモデルと経由先の課金方式を確認してください。

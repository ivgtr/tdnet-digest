# API利用料金の目安

要約に使うAPIの料金は、モデル、入力・出力トークン数、呼び出し回数によって変わります。この拡張はPDFから抽出した**テキスト**をAPIに送ります。ページ数や文字数からトークン数を正確には決められません。

## OpenRouterでの試算

以下は**2026年9月29日に確認した単価**と、仮定したトークン数による1件あたりの例です。実利用の測定値や料金の保証ではありません。単価は各モデルの[OpenRouter料金ページ](https://openrouter.ai/models)で利用直前に確認してください。

| モデル                                                                 | 入力100万トークン | 出力100万トークン | 1パスの例 | 2パスの例 |
| ---------------------------------------------------------------------- | ----------------: | ----------------: | --------: | --------: |
| [Gemini 2.5 Flash](https://openrouter.ai/google/gemini-2.5-flash)      |             $0.30 |             $2.50 |  約$0.006 |  約$0.011 |
| [Claude Sonnet 4.5](https://openrouter.ai/anthropic/claude-4.5-sonnet) |             $3.00 |            $15.00 |  約$0.045 |  約$0.084 |

この例では、**1パス**を入力合計10,000・出力1,000トークン、**2パス**をパス1が入力10,000・出力2,000トークン、パス2が入力3,000・出力1,000トークンと仮定しています。入力にはPDF本文だけでなくプロンプトも含みます。たとえばGemini 2.5 Flashの2パスは `13,000 × $0.30 / 1,000,000 + 3,000 × $2.50 / 1,000,000 = $0.0114` です。キャッシュ割引、追加の課金対象トークン、修復・再要約、クレジット購入時の手数料はこの例に含めていません。[OpenRouterの課金説明](https://openrouter.ai/support/)によると、実際の請求はプロバイダーのトークン使用量に基づきます。

## 呼び出し回数

| 要約モード | 通常の呼び出し        | 追加の呼び出し                                                                            |
| ---------- | --------------------- | ----------------------------------------------------------------------------------------- |
| 1パス      | 要約を1回生成         | なし                                                                                      |
| 2パス      | 情報抽出と整形で計2回 | 抽出結果の検証に失敗した場合は修復を1回。修復後も検証に失敗した場合は1パス要約をさらに1回 |

2パスでは、各呼び出しの入力・出力トークン数が異なります。料金が1パスの正確に2倍になるわけではありません。

## 自分の設定で見積もる

1. 設定画面で利用するプロバイダー、モデル、全文抽出または要点抽出、要約モードを確認する。
2. 契約先の最新の入力・出力トークン単価を確認する。OpenRouterではモデルと経由先により単価が異なり、クレジット購入時の手数料も別に確認する。
3. 各API呼び出しについて `（入力トークン数 × 入力単価 + 出力トークン数 × 出力単価）÷ 1,000,000` を計算し、合計する。修復や再要約も別の呼び出しとして計上する。

全文抽出ではPDF全体を入力するため、ページ数や文書の内容によって費用が増えます。要点抽出は入力を減らせますが、重要な情報を取りこぼす可能性があります。実際の費用は契約先の利用履歴・請求画面で確認してください。

# API利用料金の確認方法

要約に使うAPIの料金は、選択したプロバイダー・モデル、PDFから抽出した文字量、生成した文章量によって変わります。利用前に、契約先の最新の料金表と請求画面を確認してください。カスタムプロバイダーを使う場合も、契約先の料金が適用されます。

## 呼び出し回数

| 要約モード | 通常の呼び出し        | 追加の呼び出し                                                                            |
| ---------- | --------------------- | ----------------------------------------------------------------------------------------- |
| 1パス      | 要約を1回生成         | なし                                                                                      |
| 2パス      | 情報抽出と整形で計2回 | 抽出結果の検証に失敗した場合は修復を1回。修復後も検証に失敗した場合は1パス要約をさらに1回 |

2パスでは、各呼び出しの入力・出力トークン数が異なります。料金が1パスの正確に2倍になるわけではありません。

## 見積もり方

1. 設定画面で利用するプロバイダー、モデル、全文抽出または要点抽出、要約モードを確認する。
2. 契約先の最新の入力・出力トークン単価を確認する。
3. 各API呼び出しの入力・出力トークン数にそれぞれの単価を掛け、合計する。修復や再要約も別の呼び出しとして計上する。

全文抽出ではPDF全体を入力するため、ページ数や文書の内容によって費用が増えます。要点抽出は入力を減らせますが、重要な情報を取りこぼす可能性があります。

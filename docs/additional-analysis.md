# 論点型追加分析とPDF CMap


## 追加分析の論点化とCMap同梱（2026-10-06 / v100）

追加分析v3は固定の「解釈・短期・中期・長期」から、通常2〜4件の重要な論点へ変更する。根拠が不足する場合は1件または0件を許し、形式を埋めるための「判断不能」は要求しない。各論点は結論・根拠・条件付きの読み・限界・次の確認点を持つ。

- Backgroundは元PDFとの再照合後、確定事実に加え、点検済みの会社説明・観測指標を追加分析へ渡す。未点検/却下された説明は根拠へ昇格させない。期間形、対象、範囲、会計基準、限定条件、分割調整・分母・日付役割を保持する
- 表示する根拠本文・数量・ページはコードが構成する。モデルは根拠IDを選び、結論と読みは推論として表示する。ID照合、数値リテラル拒否、単純な重複/完全一致の拒否は意味・有用性の完全な検証ではない。因果、継続性、将来予測の正しさを保証しない
- 同条件の差額、累計実績対通期予想の残額・進捗、営業CF＋投資CFを正確な十進数で計算する。主体/範囲/基準/期間/単位/条件が不一致または曖昧な組は省略し、EPS・率・範囲値・上限/下限等を加算可能な点の金額として扱わない。利益の負数・ゼロ分母から通常の進捗率を作らない。残額は会社の残り期間予想ではない
- 根拠ページは論点ごとに重複を除き、詳細IDは展開式にする。説明/指標の不足と、入力があるのに論点を生成できなかった場合を区別する。入力件数・未整理原文・未確認事実・使用量/終了理由を残す。1要求・60秒・最大8,192出力token、暗黙の再試行なし
- 保存したv3は入力識別子と表示根拠を再照合する。全体指紋v100と `analysisCacheV3:` により旧抽出/旧時間軸形式を再利用しない。同じ結果を閉じて開き直す場合も、古い応答や保存読込で新しい分析を上書きしない
- インストール済みPDF.jsと同版のpacked CMap全体とそのLICENSEを `dist/cmaps/` へbuild/watch時に出力する。Offscreenは拡張内部URLと `cMapPacked: true` を指定する。CDN、追加ホスト権限、CSP緩和、CMapのweb-accessible公開は使わない

CMapの通常テストは実パッケージを読む `buildStart` の出力・バイト一致・監視対象・再実行時の再出力を直接確認し、Vitest内ではViteを起動しない。実ビルドへの接続は通常の `npm run build` 後に `check-cmap-artifacts.mjs` で確認する（展開済みZIPやwatch出力も引数で指定可能）。既存releaseのビルド直後にも同じ検査を実行し、プラグイン接続漏れをZIP作成前に止める。タイムアウトの一律延長や二重ビルドはしない。

今回の追加証明は部品の計算/参照/保存契約、代表的なBackground入力受渡し、実Reactの競合・閉じる/再表示、CMap資産の同梱、固定応答による指定実PDFの経路に分担する。同じ資料を全経路の語彙網羅へ複製しない。実モデル品質と実Chrome確認の境界は評価ガイドを参照する。


## 論点型追加分析・CMapの固定確認（2026-10-06 / v100）

指定資料: サーラコーポレーション（2734）、2026年11月期第3四半期、[TDnet PDF](https://www.release.tdnet.info/inbs/140120261005546285.pdf)、物理16ページ。固定SHA-256は `56aedf42833a81c078dcd4ed57c15b5a0cee3430fbbdc1e8c4ff59d6f2b53c73`。

```bash
npm run build
node evaluation/scripts/check-cmap-artifacts.mjs
node --import tsx evaluation/scripts/check-additional-analysis-sala.ts /path/to/140120261005546285.pdf
```

この一例は実PDF.js＋製品のページ抽出を使い、人が原PDFで確認した候補・説明/指標・論点の固定応答を接続する。表紙の営業利益実績8,168百万円/予想7,800百万円、本文の住宅販売/在庫処分の反動/資産売却/予想据え置き、点検済み観測指標のCFを通し、保存再検証とHTMLを確認する。CF詳細表を確定事実として無理に採用せず、既存の点検済み観測指標の経路を使う。

期待値は残額−368百万円、営業＋投資CF−11,155百万円、前年営業CF差−9,743百万円。残額を会社の最終四半期赤字予想や上方修正確定と解釈しない。固定3論点の根拠はp1/p5/p6/p11/p12、ページリンクは論点内で重複を除いて5個。結果JSON/HTMLは `evaluation/results/local/` に保存する。全事実を生成した実行ではなく、未整理原文が残ることも表示する。

CMapは168個のpacked資産＋LICENSEを同版パッケージとバイト比較し、production/watch両方とreleaseと同じZIP梱包で確認した。指定PDFをZIP内CMapで再抽出すると警告は0、追加されるのはp3〜16の共通ヘッダー各5アイテム。既存本文と座標は一致するため、CMap不足だけが薄い追加分析の原因だったとは扱わない。

今回の実API呼出しは0。固定応答は新しい入力・計算・保存・表示の契約を示すが、実モデルが論点を選ぶ品質や未知資料での成功率を示さない。実Chromeの描画・拡張通信・フォーカス確認は実施できていない。過去の画面成功を新ビルドへ読み替えない。公開前の実モデル評価が必要なら資料・モデル・回数を別途承認した範囲で固定して行う。
